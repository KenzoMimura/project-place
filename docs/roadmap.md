# Roadmap

Este documento representa a forma como este lugar pretende crescer, momento
por momento. Toda nova etapa deve respeitar os princípios presentes no
manifesto. Se uma funcionalidade entrar em conflito com esses princípios, ela
não deverá ser implementada.

## Agora — validar o lugar

- Testar os fluxos essenciais em computador e celular
- Observar pessoas reais usando o protótipo
- Registrar dúvidas, desconfortos e momentos de tranquilidade
- Corrigir problemas de acessibilidade e navegação por teclado
- Criar testes automatizados para escrita, salvamento, arquivo e exportação

## Em seguida — cuidar das palavras

- Permitir exportar todas as escritas em um arquivo seguro
- Permitir restaurar as escritas exportadas
- Tornar mais claro o estado de rascunhos e escritas finalizadas
- Avaliar busca simples somente quando o arquivo de páginas crescer

## Mais tarde — amadurecer a estrutura

- Decidir se os dados continuarão apenas no navegador
- Estudar sincronização privada sem enfraquecer a proposta do produto
- Avaliar uma migração para Next.js quando houver uma necessidade concreta
- Preservar um modo local e silencioso, mesmo se a arquitetura evoluir

## Já construído

- Tela inicial e espaço de escrita minimalista
- Modo claro e escuro
- Salvamento local no navegador
- Perguntas aleatórias
- Escritas independentes com título opcional
- Arquivo de páginas
- Finalização de escritas
- Exportação individual em PDF
- Protótipo publicado
